# ecommerce_sql_analytics
# E-Commerce Relational Database Analysis & SQL Analytics

## Project Overview
This repository contains a structured, end-to-end SQL analysis project built on relational e-commerce data. It demonstrates advanced querying techniques—ranging from foundational data validation and aggregation to complex Common Table Expressions (CTEs), window functions, customer RFM segmentation, and summary reporting layer creation.

---

## 🛠️ Tech Stack & Skills
* **Database / Engine:** MySQL / PostgreSQL / Snowflake SQL
* **SQL Techniques:** CTEs (`WITH`), Window Functions (`ROW_NUMBER()`, `RANK()`), Multi-Table `JOIN`s, Aggregations (`COUNT`, `SUM`, `AVG`), `CASE` Statements, Subqueries, & `GROUP BY / HAVING`
* **Analytics Focus:** Data Validation, Order Delivery Performance, RFM Customer Segmentation, Product Performance, and Seller Analytics
